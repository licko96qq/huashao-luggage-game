# 花少行李帮帮忙

一个面向移动端的旅行主题轻量小游戏：选择一位导游，依次挑战沙特、克罗地亚和冰岛站，在有限的行李槽中完成三消配对。

## 在线试玩

上传到 GitHub 后，可通过 GitHub Pages 发布为静态网页。发布地址通常为：

`https://<你的用户名>.github.io/<仓库名>/`

## 本地运行

项目是纯静态文件，不需要安装依赖。进入项目目录后任选一种方式启动本地服务器：

```bash
cd 花少行李帮帮忙
python3 -m http.server 4174
```

然后打开 <http://127.0.0.1:4174/>。也可以直接双击 `index.html` 试玩；使用本地服务器更接近 GitHub Pages 的运行环境。

## 游戏内容

- 导游角色：迪丽热巴、秦海璐、秦岚、辛芷蕾、赵昭仪、王安宇、胡先煦。
- 三个旅行站点：沙特、克罗地亚、冰岛；后续站点需要完成前一站解锁。
- 核心玩法：点击可见行李，将相同物品凑齐后消除，清空棋盘即可过关。
- 导游技能：暂存、加一格、交换、透视等，每局提供有限次数。
- 项目内置背景、角色、物品图片和音频数据，打开页面即可运行。

## GitHub Pages 发布

1. 在 GitHub 新建一个仓库（建议使用英文或拼音仓库名，例如 `huashao-luggage-game`）。
2. 将本目录中的全部文件上传到仓库根目录。
3. 打开仓库的 **Settings → Pages**，在 **Build and deployment** 中选择 **Deploy from a branch**。
4. Branch 选择 `main`，目录选择 `/ (root)`，点击 **Save**。
5. 等待几分钟后，访问页面顶部显示的 GitHub Pages 地址。
